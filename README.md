# Maho Inoue – personal research website

Source of the personal research website of Maho Inoue (井上 真帆), Institute of Botany and Landscape Ecology, University of Greifswald.
Research on slime moulds (Myxomycetes) and club mosses (*Diphasiastrum*, Lycopodiaceae).

Website: https://mh-in.github.io/minoue.github.io/

The site is plain static HTML served by GitHub Pages. All pages share `styles.css`; English and Japanese pages come in pairs
(`index.html` / `index-jp.html`, `research-*.html` / `research-*-jp.html`, `cv.html` / `cv-jp.html`).

研究用の個人サイトのソースです。英語版と日本語版のページが対になっています。

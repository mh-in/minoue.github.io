産地
判定の厳しさ：
  • 標準（おすすめ）：除外に使う形質（「まず見る形質」）が記載と食い違えば、候補から外します。
  • 厳密：すべての形質で、食い違えば外します。皮層のように種内で変わる形質でも外すので、誤観察に弱くなります。
  • 緩和：どの形質でも外さず、観察に合う度合いで並べるだけにします。
  • どのモードでも、推定（◐）・係争中（？）のセルでは外しません。

●＝記載あり　◐＝記載からの推定　？＝係争中（本文の中で記述が食い違う）　✎＝他文献からの候補（未裁定）　—＝記載なし（判定では中立）。 ◐ と ？ のセルは、観察と食い違っても候補から外しません（警告と順位の減点のみ）。 出典の値が割れているセルは、片方に寄せずに併記しています（例：胞子径「Poulain 6–8／Stephenson 8–9」）。 セルにマウスを置くと出典が出ます。複数の状態が並んでいる場合は「そのいずれか、または同一標本で混在」を意味します。 信頼度は「高／中／低」、除外は「この形質が食い違えば候補から外す」の意味です。

状態の判定は形容詞ではなく画像で合わせるのが確実です。 最初に胞子の比較（決め手になる胞子を4種並べたもの）、 続いて状態ごとの見本（本文が「Fig. 5M」のように図を名指ししている箇所を対応させたもの）、 最後にパネル単位の図版一覧です。パネルの内容は図の脚注に従い、行の意味は種によって違うので注意してください （例：jurana は D が着合子嚢体、tasmanica は D が皮層）。

手元の Sanger リードを貼ると、この論文の参照配列（nucSSU 45本・mtSSU 28本＋対外群5本）の中で 最も近いものと、その種・リボタイプを表示します。判定は k-mer（12塩基）の含有率で、 相同率ではありません。BLAST の代替ではなく、当たり付けの道具です。 リボタイプの細分（rt1a と rt2 など）は原理的に区別できないので、種レベルで読んでください。

これは何か

分類学的な「検索表」を、分岐式ではなく多項目選択（multi-access key）として作った試作です。 観察できた形質だけを入れると候補が絞られ、次に観るべき形質を1つ提示します。 分岐式のように「最初の質問を間違えると最後まで別の種に着く」ことがありません。

設計上、意図的にやっていること

  • 空欄は中立。この論文に記載がない形質は、除外にも支持にも使いません。空欄を「その形質がない」と解釈すると、記載の薄い種が不当に落ちます。
  • 除外は信頼できる形質だけ。皮層のように種内で変動する形質は、食い違っても警告に留めます（標準モード）。厳密モードでは全形質で除外します。
  • 同点は同点として出す。無理に1種に決めません。
  • 未記載系統を警告として持つ。形態未記載の分子系統（Reticularia sp., splendens rt3）は、jurana か splendens が候補に1つでも残っていれば警告します。形態では区別できないことが要点なので、出し漏れを避けています。既知の産地は参考として添えますが、絞り込みには使いません（既知の標本が数点しかないため）。
  • 推定は推定と表示する。jurana と splendens の「網目以外の装飾」は診断文からの推定で、原記載には明記がありません。
  • 推定・係争中のセルでは除外しない。◐（推定）と ？（係争中）のセルは、観察と食い違っても候補から外さず、警告と順位の減点に留めます。そのため tasmanica と jurana、lucidula と splendens は、場合によっては両方が候補に残ります。論文の記述から確実に言えるのがそこまでだからです。

この試作の限界

  • 根拠は1論文とその補足表のみ。5種のうち完全な種記載があるのは lucidula と tasmanica の2種だけです。
  • lycoperdon は本論文に種記載がなく、6セルはすべて他文献（Poulain 2011、Stephenson 2003）からの候補（✎）です。
  • 配列の照合は 12-mer の含有率による当たり付けです。種レベルの一致は参照内で検証済み（45/45、28/28）ですが、 リボタイプの細分（rt1a と rt2 など）は原理的に区別できません。相同率でもありません。
  • 2新種はそれぞれ単一地域の標本に基づくため、種内変異（特に胞子装飾）は未評価です。論文自身がそう述べています。
  • 胞子装飾の判定には染色・油浸と、比較用の参照画像が必要です。Fig. 3–6 を「図版」タブに収録しましたが、倍率・染色条件を揃えた自分の標本で確認してください。
